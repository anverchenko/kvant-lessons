Етапи уроку
    Етап 1 · Вступ

    Коли відповідей дві, а не одна

    Ти вже вмієш розв'язувати рівняння виду ax + b = 0 — там відповідь завжди одна. Але щойно невідоме потрапляє у квадрат, світ змінюється: відповідей може бути дві, одна або взагалі жодної.

    Задача, з якої все почалося

    Прямокутна ділянка на 3 м довша, ніж ширша, а її площа — 54 м². Якою є ширина?

    Позначимо ширину через x. Тоді довжина — x + 3, а площа:

    x(x + 3) = 54   ⟶   x2 + 3x − 54 = 0

    Підбором корінь знайти можна — але лише поки числа зручні. Сьогодні ти отримаєш інструмент, який працює завжди: дискримінант.

    Що буде в кінці уроку

    Ти зможеш подивитися на будь-яке квадратне рівняння й за пів хвилини сказати: скільки в нього коренів і які саме.

    Етап 2 · Мета

    Мета уроку

    До кінця заняття ти вмітимеш робити чотири речі — і кожну з них ми відпрацюємо.

    1. Упізнавати квадратне рівнянняі правильно виписувати коефіцієнти a, b, c — разом зі знаками.
    2. Обчислювати дискримінантза формулою D = b2 − 4ac без помилок у знаках.
    3. Визначати кількість коренівза знаком D — ще до того, як щось розв'язувати.
    4. Знаходити самі кореніза формулою та перевіряти їх підстановкою.

    Що треба знати заздалегідь

    • Квадрат числа і квадратний корінь: 72 = 49, √49 = 7
    • Дії зі знаками: мінус на мінус дає плюс
    • Розкриття дужок і зведення подібних доданків
    Етап 3 · Медіа

    Подивись, перш ніж рахувати

    Кожному квадратному рівнянню відповідає крива — парабола. Корені рівняння — це точки, де вона перетинає вісь x. Звідси й уся інтуїція: перетинів може бути два, один або жодного.

    Малювати графік щоразу — довго й неточно. Дискримінант дає ту саму відповідь одним обчисленням: він вимірює, наскільки глибоко парабола «занурена» за вісь.

    Етап 4 · Ключові поняття

    Три коефіцієнти й одне число

    Перш ніж рахувати, рівняння треба звести до стандартного вигляду — усе в лівій частині, нуль у правій.

    ax2 + bx + c = 0,  де a ≠ 0
    a — старший коефіцієнтСтоїть при x2. Не може дорівнювати нулю: інакше рівняння перестає бути квадратним.
    b — другий коефіцієнтСтоїть при x. Може бути будь-яким числом, зокрема від'ємним чи нулем.
    c — вільний членЧисло без x. Теж може бути від'ємним або нулем.

    Найчастіша помилка — знаки

    Рівнянняabc
    2x2 − 5x − 3 = 02−5−3
    x2 + 4 = 0104
    −x2 + 5x − 6 = 0−15−6

    Знак «мінус» належить коефіцієнту, а не залишається в рівнянні. Виписуй a, b, c разом зі знаками — і половина помилок зникне.

    Етап 5 · Пояснення

    Звідки береться дискримінант

    Формулу не треба приймати на віру — її можна вивести. Ідея одна: перетворити рівняння на вигляд (щось)2 = число, бо такі рівняння ми вже вміємо розв'язувати.

    ax2 + bx + c = 0— початкове рівняння x2 + bax + ca = 0— поділили на a (x + b2a)2 = b24a2 − ca— виділили повний квадрат (x + b2a)2 = b2 − 4ac4a2— звели до спільного знаменника

    Ось воно. Уся доля рівняння залежить від виразу в чисельнику — саме його назвали дискримінантом (від латинського discriminare — «розрізняти»).

    D = b2 − 4ac

    Ліворуч стоїть квадрат — а квадрат ніколи не буває від'ємним. Тому якщо D < 0, рівність неможлива: дійсних коренів немає. Якщо ж D ≥ 0, добуваємо корінь з обох частин і отримуємо готову формулу:

    x = −b ± √b2 − 4ac2a = −b ± √D2a
    Етап 6 · Пояснення

    Три випадки — і жодного іншого

    Знак дискримінанта повністю визначає, скільки коренів має рівняння. Це можна побачити на графіку й перевірити обчисленням.

    Знак DКоренівЩо відбувається
    D > 0Два різніПід коренем додатне число, «±» дає дві різні відповіді. Парабола перетинає вісь двічі.
    D = 0Один√0 = 0, і «±» уже нічого не змінює: x = −b2a. Парабола торкається осі.
    D < 0ЖодногоКорінь з від'ємного числа серед дійсних чисел не існує. Парабола не дістає до осі.

    Практичний висновок. Якщо в задачі питають лише «скільки коренів?» — рахуй D і зупиняйся. Далі можна не розв'язувати.

    Етап 7 · Розібраний приклад

    Приклад із двома коренями

    Розв'яжемо разом, крок за кроком: 2x2 − 5x − 3 = 0

    1. Виписуємо коефіцієнти зі знакамиa = 2,  b = −5,  c = −3
    2. Рахуємо дискримінантD = (−5)2 − 4·2·(−3) = 25 + 24 = 49  — зверни увагу: −4·2·(−3) дало плюс 24.
    3. Перевіряємо знак49 > 0 → буде два корені. Одразу знаходимо √49 = 7.
    4. Підставляємо у формулуx = 5 ± 74  →  x1 = 124 = 3,   x2 = −24 = −0,5
    5. Перевіряємо підстановкою2·32 − 5·3 − 3 = 18 − 15 − 3 = 0 ✓

    Ключовий момент кроку 4

    У формулі стоїть −b. Оскільки b = −5, то −b = +5. Це місце, де губиться найбільше балів.

    Ще два випадки — коротко

    x2 − 6x + 9 = 0

    D = 36 − 36 = 0 → один корінь: x = 62 = 3

    x2 + x + 3 = 0

    D = 1 − 12 = −11 → коренів немає. Далі не рахуємо.

    Етап 8 · Пам'ятка

    Алгоритм, який працює завжди

    Шість кроків — у цьому порядку. Він не змінюється залежно від рівняння.

    1. Звести до стандартного виглядуУсе перенести ліворуч, справа залишити нуль, звести подібні.
    2. Виписати a, b, cОбов'язково зі знаками. Якщо доданка немає — коефіцієнт дорівнює нулю.
    3. Обчислити D = b2 − 4acСпочатку b2 (завжди додатне), потім 4ac зі своїм знаком.
    4. Подивитися на знак DВід'ємний — пишемо «коренів немає» і зупиняємось.
    5. Знайти кореніx = −b ± √D2a — риска ділить увесь чисельник.
    6. Перевірити підстановкоюХоча б один корінь. Це 20 секунд, які рятують відповідь.
    Етап 9 · Перша спроба

    Тепер ти

    Розв'яжи самостійно, на папері, за алгоритмом. Потім впиши відповіді — я перевірю.

    Завдання
    x2 − 7x + 12 = 0

    Порядок коренів не має значення — впиши їх у будь-якій послідовності.

    Етап 10 · Фідбек після першої спроби

    Де зазвичай губляться бали

    Правильна відповідь: D = 49 − 48 = 1, звідки x = 7 ± 12, тобто 4 і 3. Якщо вийшло інакше — швидше за все, справа в одному з цих чотирьох місць.

    Знак перед b

    Записують x = −7 ± 12 замість 7 ± 12. У формулі стоїть −b, а b тут уже від'ємне.

    Квадрат від'ємного числа

    Пишуть (−7)2 = −49. Квадрат будь-якого числа не буває від'ємним: (−7)2 = 49.

    Ділення лише частини чисельника

    Ділять на 2a тільки √D. Дробова риска охоплює увесь вираз −b ± √D.

    Пропущений стандартний вигляд

    Беруть коефіцієнти з рівняння x2 = 7x − 12 як є. Спочатку — усе ліворуч, і лише потім a, b, c.

    Якщо все зійшлося — ти вже вмієш головне. Наступний крок: навчитися не збиватися, коли коефіцієнти незручні.

    Етап 14 · Далі

    Куди рухатись далі

    Дискримінант — універсальний інструмент, але не завжди найшвидший. Ось що логічно вивчити наступним.

    Теорема ВієтаДля зведеного рівняння сума коренів дорівнює −b, а добуток — c. Часто корені видно без обчислень.
    Неповні квадратні рівнянняКоли b = 0 або c = 0 — там дискримінант не потрібен зовсім.
    Розкладання на множникиax2 + bx + c = a(x − x1)(x − x2) — прямий наслідок сьогоднішньої формули.
    Задачі на складання рівняньПовернення до ділянки з першого етапу: x2 + 3x − 54 = 0. Порахуй D — і знайди ширину.

    Домашнє завдання

    • 3x2 − 7x + 2 = 0
    • x2 + 10x + 25 = 0
    • 2x2 − x + 4 = 0
    • x(x + 3) = 54  — та сама ділянка
