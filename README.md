Публічні сторінки уроків онлайн-школи «КВАНТ».

**Каталог:** https://anverchenko.github.io/kvant-lessons/

## Уроки

| Тема | Предмет | Клас |
|---|---|---|
| [Квадратне рівняння: розв'язування через дискримінант](https://anverchenko.github.io/kvant-lessons/dyskryminant/) | Алгебра | 8 |

## Документи

- [Зовнішня розробка уроків та експорт у Квант](https://anverchenko.github.io/kvant-lessons/eksport/) — контракт обміну між автором і платформою

## Структура

```
index.html          каталог: документ угорі + перелік уроків (масив LESSONS)
<урок>/index.html   сторінка уроку
eksport/index.html  документ, згенерований із docs/ у проєкті Kvant
```

Кожна сторінка автономна: без зовнішніх залежностей, працює офлайн,
дані нікуди не надсилаються.

## Як додати урок

1. Створити теку `<назва-уроку>/` з файлом `index.html`.
2. Додати запис у масив `LESSONS` у кореневому `index.html`:
   тема, предмет, клас, опис, кількість етапів, тривалість.
3. Закомітити й запушити — GitHub Pages оновиться за хвилину.

## Як оновити документ

```
python tools/md2page.py docs/<файл>.md site/<тека>/index.html --subtitle "..."
```
