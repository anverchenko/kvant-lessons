# Діагностика КВАНТ

Публічні сторінки онлайн-школи «КВАНТ».

**Каталог:** https://anverchenko.github.io/kvant-lessons/

## Матеріали

| Матеріал | Предмет | Формат |
|---|---|---|
| [Вхідна діагностика НМТ-2026: варіант 1](https://anverchenko.github.io/kvant-lessons/NMT/variant-1/) | Математика | 22 завдання, 32 бали |
| [Вхідна діагностика НМТ-2026: варіант 2](https://anverchenko.github.io/kvant-lessons/NMT/variant-2/) | Математика | 22 завдання, 32 бали |

## Структура

```
index.html               каталог: перелік матеріалів (масив LESSONS)
NMT/variant-1/index.html варіант 1 діагностики
NMT/variant-2/index.html варіант 2 діагностики
```

Кожна сторінка автономна: без зовнішніх залежностей, працює офлайн,
дані нікуди не надсилаються. Рисунки вбудовані в HTML як SVG.

## Як оновити діагностику

Сторінки збираються в робочому проєкті Kvant, а сюди переносяться готовими:

```
python tools/build_nmt.py            # збирає site/NMT/variant-*/index.html
python tools/check_nmt.py            # незалежно перевіряє ключі та рисунки
```

Потім скопіювати обидва `index.html` у `NMT/variant-*/`, закомітити й запушити —
GitHub Pages оновиться за хвилину.

## Як додати матеріал

1. Створити теку `<назва>/` з файлом `index.html`.
2. Додати запис у масив `LESSONS` у кореневому `index.html`:
   назва, предмет, формат, опис, кількість завдань, бали.
3. Закомітити й запушити.
