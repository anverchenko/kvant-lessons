# Уроки КВАНТ

Публічні сторінки уроків онлайн-школи «КВАНТ».

**Каталог:** https://anverchenko.github.io/kvant-lessons/

## Уроки

| Тема | Предмет | Клас |
|---|---|---|
| [Квадратне рівняння: розв'язування через дискримінант](https://anverchenko.github.io/kvant-lessons/dyskryminant/) | Алгебра | 8 |

## Структура

```
index.html          каталог уроків (перелік у масиві LESSONS)
<урок>/index.html   сама сторінка уроку
```

Кожен урок — одна автономна HTML-сторінка: без зовнішніх залежностей,
працює офлайн, дані нікуди не надсилаються.

## Як додати урок

1. Створити теку `<назва-уроку>/` з файлом `index.html`.
2. Додати запис у масив `LESSONS` у кореневому `index.html`:
   тема, предмет, клас, опис, кількість етапів, тривалість.
3. Закомітити й запушити — GitHub Pages оновиться за хвилину.
